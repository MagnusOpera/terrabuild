---
title: version
---

`terrabuild version` prints the installed Terrabuild version and exits successfully.

```text
USAGE: terrabuild version
```

## Example

```bash
terrabuild version
```

The output has the form `Terrabuild v<version>`. Use it when checking which binary is installed locally or in CI, or when reporting a problem. It does not require a `WORKSPACE` file or an Insights connection.
